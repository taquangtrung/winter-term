# Winter guide

How to use Winter day to day, one page per tool. For what Winter is and how to install it, see the [README](../../README.md). For how it is built, see [`architecture.md`](../internals/architecture.md).

## Getting around

- [Basics](basics.md): windows, panes, tabs, panels, the status bar, and notifications.
- [Modes](modes.md): Insert, Normal, and Visual in a terminal.
- [Keys](keys.md): every built-in key, and how to rebind keys in `keybindings.kdl`.
- [Pickers](pickers.md): the command palette, finding files, project search, and the other lists.
- [Terminal](terminal.md): shell integration, rich blocks, and the multiplexer.
- [Agents](agents.md): AI coding agents, each on a branch and in a checkout of its own.

- [Git](git.md): status, staging, commits, history, and commit messages.

- [Viewers](viewers.md): images, hex, the Markdown preview, and Open With.
